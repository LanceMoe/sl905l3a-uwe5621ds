# 有界 SRAM 描述符链 RX 候选

仅绑定 CM311 的 ffe03000 SDIO 主机；不接管 eMMC。
来源：unifreq/linux-6.18.y v6.18.37 的 meson-gx-mmc.c。

超过 1536 字节的 function 1 / 地址 0x20 固定地址接收，使用单条 CMD53、
同一条片内 SRAM 描述符链，最多 8 个 512 字节块。
描述符放在 0x200，两个数据缓冲区在 0x400、0x600 交替使用。
CPU 按所有权归还顺序取走数据，不在数据段之间重启控制器。
发送仍限 1536 字节，ROM/寄存器请求保持原路径。

目前 SDIO 时钟保守限制为 1 MHz。仅在大包接收期间屏蔽主机 IRQ 并短暂关闭
本地中断，轮询上限 100 ms；检测 CRC、超时和缓冲区覆盖，失败时不报告成功。
该候选尚未通过硬件验收，未纳入通用安装器或稳定发行包。

先前“EOC 后重新启动 NO_CMD”的候选未能在硬件上保留数据阶段，已撤销。
本目录实现使用连续描述符链；模型仅能验证代码与假控制器，不能替代硬件验收。
